# netgram

<img src="Telegram/Resources/art/netgram/png/icon_256.png" width="96" alt="Логотип netgram">

**netgram** — неофициальный клиент Telegram для компьютеров, рассчитанный на сети с DPI-ограничениями. Он основан на исходном коде [Telegram Desktop][tdesktop] и сохраняет все его функции. Сверху добавлены способы обхода блокировок, функции приватности и истории сообщений, а интерфейс полностью переведен на русский.

> Это неофициальная сборка, она не связана с Telegram FZ-LLC. Используйте на свой риск.

---

## Возможности

### Подключение в сетях с ограничениями

- **Встроенный WSS-транспорт.** MTProto поверх WebSocket к веб-релеям Telegram (DC2/DC4). Включен по умолчанию: свежая установка подключается сразу, без настройки прокси.
- **Маскировка MTProxy (FakeTLS).** Клиент повторяет TLS-рукопожатие настоящего браузера: профили ClientHello (Auto, Auto-rotate, Firefox, Yandex, Android OkHttp и др.), фрагментация ClientHello, разные размеры TLS-записей, сглаживание трафика в начале сессии, правдоподобные повторные подключения.
- **Надежное переподключение.** Ограниченные паузы между попытками, временное понижение приоритета узлов, которые только что отвалились, разнос одновременных подключений.
- **Защита от случайного прямого подключения.** Без прокси и без WSS клиент в сеть не выходит.
- **Спокойный список прокси.** Открытие окна не запускает проверку всех прокси сразу, проверка — по кнопке.
- **Быстрое подключение.** Убраны лишние клиентские задержки: очередь дозвонов и алгоритм Нейгла (`TCP_NODELAY`).

### Приватность и история сообщений

- **Режим призрака** с отдельными настройками: не отправлять «прочитано», «онлайн», «печатает», отметки просмотра историй.
- **Удаленные и измененные сообщения.** Удаленные сообщения остаются в переписке с пометкой, у измененных можно посмотреть прежние версии.
- **Истории.** Локальное сохранение историй и скачивание любых, в том числе защищенных от пересылки.
- **Фильтры сообщений** по регулярным выражениям, режим стримера, локальный Premium.
- **Защищенные группы (e2e_cloud, в разработке).** Сквозное шифрование сообщений и файлов в группах нового типа: Telegram хранит только зашифрованные данные.

### Интерфейс

- Полностью русский интерфейс, включая все дополнительные функции.
- Настройка шрифтов, скругления аватарок, значков приложения и внешнего вида.
- Переводчик сообщений и превью медиа.

## Установка

Готовые сборки будут публиковаться в разделе [Releases](https://github.com/defl0r1an/netgram/releases) репозитория `defl0r1an/netgram`. Пока релизов нет.

Встроенный обновлятор проверяет те же GitHub Releases. Пакеты обновлений подписаны ключом netgram, пакеты от других клиентов не принимаются.

---

## Сборка

Исходный код вместе со всеми зависимостями:

```
git clone --recursive https://github.com/defl0r1an/netgram.git
```

- Windows-сборка x64 собирается в GitHub Actions: [`.github/workflows/win.yml`](.github/workflows/win.yml). Готовые `netgram.exe` и `Updater.exe` сохраняются как артефакт запуска.
- Быстрые проверки исходников: [`.github/workflows/source-guards.yml`](.github/workflows/source-guards.yml). Список обязательных проверок — `Telegram/SourceFiles/tests/release_guards.txt`.
- Ручная сборка описана в [`docs/`](docs/): [Windows](docs/building-win.md), [macOS](docs/building-mac.md), [Linux](docs/building-linux.md).
