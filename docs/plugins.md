# Плагины netgram

Раздел находится в настройках netgram → «Плагины». Python-среда входит в
Windows-сборку и установщик; отдельно устанавливать Python не требуется.

Для установки своего файла включите «Разрешить установку из файлов», прочитайте
подтверждение и нажмите «Установить плагин из файла». Поддерживаются `.plugin`
и `.py`. Перед установкой можно просмотреть код и результаты анализа файла.
Анализ помогает заметить обращения к сообщениям, сети и файлам, но не является
изоляцией исполняемого кода или гарантией безопасности.

Установленные плагины можно включать и отключать, удалять, настраивать и
экспортировать. Безопасный режим отключает исполнение всех плагинов. После
неудачного запуска или обнаруженного зависания движок переключается в него
автоматически. Выключение самого движка требует перезапуска приложения.

В первом этапе подключены изменение и отмена отправки текстовых сообщений,
уведомления о новых сообщениях, пункты меню сообщений, чатов и главного меню,
настройки и интерфейс плагинов, а также отправка запросов через API движка.
Python SDK сохраняет совместимые имена модулей и формат метаданных.

Перехват произвольных Java-методов, Android-конструкторов и работа с Android
DEX не реализованы. Глобальный перехват всех MTProto-запросов клиента также
не подключён. Совместимость каждого стороннего плагина нужно проверять отдельно;
успешная установка файла ещё не подтверждает работу всех его функций.

Файлы плагинов и их настройки находятся внутри каталога данных клиента:
`tdata/plugins/`. Настройки движка — `tdata/plugin_preferences.json`.
Предустановленных доверенных каналов нет; разрешение установки из файлов
выключено по умолчанию.
