# Плагины netgram

Раздел находится в настройках netgram → «Плагины». Python-среда входит в
Windows-сборку и установщик; отдельно устанавливать Python не требуется.

Для установки своего файла включите «Разрешить установку из файлов», прочитайте
подтверждение и нажмите «Установить плагин из файла». Поддерживаются `.plugin`,
`.py`, `.elyx` и `.eaf`. Перед установкой можно просмотреть код и результаты
локального анализа. Плагины запрашивают разрешения на доступ к сети и папкам;
эти разрешения можно отозвать в настройках плагина. Анализ и ограничения доступа
не гарантируют безопасность произвольного кода. Отдельного процесса для плагинов
пока нет. Внешние модели и списки доверенных каналов автоматически не загружаются.

Установленные плагины можно включать и отключать, удалять, настраивать и
экспортировать. Безопасный режим отключает исполнение всех плагинов. После
неудачного запуска или обнаруженного зависания движок переключается в него
автоматически. Выключение самого движка требует перезапуска приложения.

Подключены изменение и отмена отправки текстовых сообщений, уведомления о новых
сообщениях, пункты меню сообщений, чатов, профилей и главного меню, события
перехода между экранами и состояния приложения, настройки и интерфейс плагинов,
а также отправка запросов через API движка. Коды входа из служебного чата
плагинам не передаются. Python SDK сохраняет совместимые имена модулей и формат
метаданных. Для Linux и macOS требуется именно Python 3.11.

Добавлена эмуляция распространённых Java/Android-классов и перехватов отправки,
уведомлений и экранов. Настоящей JVM/Android и поддержки DEX нет: произвольные
методы Android поддерживаются только там, где есть реализация совместимости.
Глобальный перехват всех MTProto-запросов клиента также не подключён.
Совместимость каждого стороннего плагина нужно проверять отдельно; успешная
установка файла ещё не подтверждает работу всех его функций.

Из меню плагина можно запустить адаптацию его кода через ИИ. Она требует
явного действия пользователя и собственного API-ключа выбранного сервиса
либо локального сервера. Код выбранного плагина отправляется этому сервису;
результат проверяется перед установкой. Автоматически такая отправка не происходит.

Файлы плагинов и их настройки находятся внутри каталога данных клиента:
`tdata/plugins/`. Настройки движка — `tdata/plugin_preferences.json`.
Предустановленных доверенных каналов нет; разрешение установки из файлов
выключено по умолчанию.
