# Участие в разработке netgram

Ошибки, предложения и обсуждения принимаются в разделе Issues репозитория:

<https://github.com/defl0r1an/netgram/issues>

## Требования к изменению

- одна задача должна решать одну понятную проблему;
- нельзя смешивать функциональную правку с массовым форматированием;
- перед отправкой нужно выполнить проверки из
  `Telegram/SourceFiles/tests/release_guards.txt`;
- Windows-изменения дополнительно проверяются Release-сборкой;
- сообщение коммита должно объяснять не только что изменено, но и зачем;
- секреты, ключи подписи, журналы и готовые локальные конфигурации в Git не
  добавляются.

Адрес репозитория:

```text
git clone --recursive https://github.com/defl0r1an/netgram.git
```

Синхронизацию с исходным Telegram Desktop выполняет сопровождающий проекта
отдельными проверяемыми обновлениями.

Инструкции по подготовке среды находятся в каталоге [`docs`](.).
