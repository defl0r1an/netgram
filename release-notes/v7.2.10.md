Первый выпуск **netgram** — клиента Telegram для компьютера, рассчитанного на сети с DPI-ограничениями. Основан на Telegram Desktop 7.2.10.

## Что внутри

- **Обход блокировок:** встроенное подключение через веб-сокеты (WSS), MTProxy с маскировкой под обычный HTTPS, выбор браузера для маскировки, свой WSS-ретранслятор.
- **Приватность:** режим призрака (не отправлять «прочитано», «в сети» и «печатает»), режим стримера, скрытие рекламы.
- **История сообщений:** сохранение удаленных и отредактированных сообщений, история правок, защита от удаления.
- **Удобства:** фильтры сообщений, шрифты, выбор иконки приложения, ID и дата регистрации в профиле, ускорение и усиление медиа.
- **Русский интерфейс:** все собственные функции переведены.

## Установка

1. Скачайте `netgram-7.2.10-win64-portable.zip` ниже и распакуйте в любую папку.
2. Запустите `netgram.exe`.

Данные хранятся в `%APPDATA%\netgram` и не пересекаются с официальным Telegram Desktop.

Программа не подписана сертификатом, поэтому при первом запуске Windows SmartScreen может показать предупреждение «Неизвестный издатель» — нажмите «Подробнее» → «Выполнить в любом случае».

Проверить архив можно по контрольной сумме из файла `.sha256`.
