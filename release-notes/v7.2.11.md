## Что нового

- **Стабильнее резервное подключение:** соединения через WSS-туннель распределяются между тремя серверами. Когда у одного кончается суточный лимит, netgram сразу переходит на следующий, и медиа продолжают грузиться.
- **Дата регистрации в профиле:** кнопка снова есть у пользователей — по нажатию показывается примерная дата создания аккаунта.
- **Значок прокси:** при системных настройках прокси вместо пустого круга слева внизу показывается перечеркнутый щит; по нажатию открываются настройки прокси.
- **Настройки прокси** переписаны понятным русским языком.
- **Смена иконки приложения** теперь предлагает перезапуск, чтобы иконка обновилась везде.

## Установка и обновление

Уже установленный netgram 7.2.10 обновится сам.

Для новой установки:
- **Установщик:** `netgram-7.2.11-win64-setup.exe`. Права администратора не нужны, netgram ставится в `%APPDATA%\netgram`.
- **Без установки:** `netgram-7.2.11-win64-portable.zip` — распакуйте и запустите `netgram.exe`.

Программа не подписана сертификатом, поэтому Windows SmartScreen может показать предупреждение «Неизвестный издатель» — нажмите «Подробнее» → «Выполнить в любом случае».

Контрольные суммы — в `netgram-7.2.11-SHA256SUMS.txt`. Файлы `current6` и `tx64upd7002011` служебные, их использует автообновление.
